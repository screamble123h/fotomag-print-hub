# FotoMag Print Hub

Публичная мобильная страница FotoMag для печати фото и документов с телефона. Клиент выбирает бот VK/MAX/Telegram или прямой контакт.

Источник: утвержденный дизайн FotoMag, реальная фотография фасада, оригинальный логотип. Публичная страница не хранит присланные клиентами файлы.
