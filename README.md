# FotoMag Print Hub — мобильный портал

Публичный адрес: https://screamble123h.github.io/fotomag-print-hub/

## FotoMag 2.0 — сервисные карточки
- Боты ВКонтакте, MAX и Telegram находятся на первом экране. Сайт направляет в мессенджеры; самостоятельно файлы не получает и не хранит.
- Ниже размещены выбор услуг, ориентировочные цены и FAQ. Обслуживание в самом магазине не подменяется заказом в боте.
- При нажатии «Выбрать бота» сайт показывает подсказку и позволяет скопировать текст обращения. Этот выбор **не передаётся в бот автоматически**: клиент открывает чат и указывает нужную услугу.
- Цены — ориентир по подтверждённому рабочему прайсу, окончательная сумма уточняется до оплаты.
- Нет онлайн-оплаты, корзины и собственного трекинга заказов. Нельзя считать файл принятым, пока заказ не подтверждён в рабочем канале.

## Обновление и безопасность
- Ветка `main` защищена GitHub ruleset: обязательный Pull Request и проверка `Validate site security`.
- Скрипт проверки: `python scripts/verify_public_site.py`; запрещены неожиданные домены, формы, inline-обработчики, опасные клиентские функции и неподтверждённые назначения.
- CSS/JS локальные и загружаются по HTTPS; политика CSP размещена в HTML meta. Настройки HTTP-заголовков зависят от GitHub Pages.
- Все изменения проверять на узких телефонах и с клавиатуры, а также тестировать переходы к трём ботам. Реальную отправку файла и получение заказа проверять отдельно на тестовых учётных записях, не затрагивая клиентов.

## Будущий мини-магазин
В данный выпуск магазин не входит. Планируется отдельный раздел канцтоваров: файлы, папки, бумага, ручки, тетради и обложки. Товары, цены и остатки публиковать только после сверки с магазином. Корзину и резервирование подключать лишь к подтверждённому приёмщику заказов; скрытых ключей в браузере быть не должно.
