GitHub Pages обслуживает статическую главную и каталоги. Личные контакты, боты и отдельная форма прямой загрузки — три разных маршрута. Публичный API не считается включённым при пустом `fotomag-upload-api`; работа локальной формы и доставка на рабочий ПК проверяются отдельно. Открытие чата не отправляет заявку, а приём заявки сервером не доказывает запись файлов на D:.

В каталоге кружек сохраняются 139 товаров, 31 серия и 138 подтверждённых изображений. Две подтверждённые розничные цены: классическая белая — 650 ₽; молочник, артикул 10335 — 1250 ₽. Для остальных моделей цену уточняют. Направлений фотосувениров — 28; группировка и объяснение ранее встречавшегося числа 27 приведены в PROJECT.md.

Публикация осуществляется через Pull Request и обязательный **Validate site security**. Успешный локальный тест, контроль Codex или подготовленный комплект не заменяют успешный CI, выпуск и проверку по публичному адресу. Текущий фактический статус следует читать в протоколе приёмки.

## FotoMag 2.0 — сервисные карточки
- Боты ВКонтакте, MAX и Telegram находятся на первом экране. Сайт направляет в мессенджеры; самостоятельно файлы не получает и не хранит.
- Ниже размещены выбор услуг, ориентировочные цены и FAQ. Обслуживание в самом магазине не подменяется заказом в боте.
- При нажатии «Выбрать бота» сайт показывает подсказку и позволяет скопировать текст обращения. Этот выбор **не передаётся в бот автоматически**: клиент открывает чат и указывает нужную услугу.
- Цены — ориентир по подтверждённому рабочему прайсу, окончательная сумма уточняется до оплаты.
- Нет онлайн-оплаты, корзины и собственного трекинга заказов. Нельзя считать файл принятым, пока заказ не подтверждён в рабочем канале.

## Обновление и безопасность
- Ветка `main` защищена GitHub ruleset: обязательный Pull Request и проверка `Validate site security`.
- Скрипт проверки: `python scripts/verify_public_site.py`; запрещены неожиданные домены, формы, inline-обработчики, опасные клиентские функции и неподтверждённые назначения.
- CSS/JS локальные и загружаются по HTTPS; политика CSP размещена в HTML meta. Настройки HTTP-заголовков зависят от GitHub Pages.
- Все изменения проверять на узких телефонах и с клавиатуры, а также тестировать переходы к трём ботам. Реальную отправку файла и получение заказа проверять отдельно на тестовых учётных записях, не затрагивая клиентов.

## Будущий мини-магазин
В данный выпуск магазин не входит. Планируется отдельный раздел канцтоваров: файлы, папки, бумага, ручки, тетради и обложки. Товары, цены и остатки публиковать только после сверки с магазином. Корзину и резервирование подключать лишь к подтверждённому приёмщику заказов; скрытых ключей в браузере быть не должно.

## Фото на документы за 450 ₽ — простой путь отправки

Для формата 3×4 см (6 шт. на листе 10×15 см) клиент открывает #order450, нажимает крупную кнопку «Отправить фото в Telegram, MAX или ВКонтакте». В личном чате FotoMag нужно нажать скрепку или +, выбрать снимок из галереи, написать короткую фразу «Фото на документы 3×4, 450 ₽» и отправить. Большая инструкция по прикреплению фото находится прямо под кнопками. Подробный текст и копирование намеренно спрятаны под необязательным раскрывающимся пунктом. При прокрутке этой секции нижняя плавающая навигация скрывается, чтобы не перекрывать элементы. Отдельно есть кнопка электронной почты с подготовленным письмом, куда снимок нужно прикрепить вручную.

**Сайт не загружает файлы самостоятельно, не подтверждает заказ и не хранит фотографии**; клиентская фотография пересылается в конкретном мессенджере/почте, где сотрудник проверяет снимок, стоимость и готовность. Для других форматов цену нужно отдельно согласовать. Веб-проверка не заменяет реального контрольного заказа через авторизованный мессенджер.

## 18.11.2026 — единая кнопка «Отправить лично»
Вместо четырёх постоянно видимых вариантов в заказе фото 450 ₽ теперь одна крупная кнопка
«Отправить лично». Нажатие раскрывает ровно четыре способа связи: ВКонтакте, MAX,
электронная почта и Telegram. Других копий списка личных каналов на странице нет.
У первого блока с ботами тоже есть быстрый переход к тому же раскрываемому разделу.
Обычные боты VK/MAX/TG остаются отдельным способом автоматического оформления.
В личном сообщении фотография прикрепляется скрепкой/плюсом в самом приложении,
сайт не хранит и не отправляет файлы автоматически. Для 450 ₽ клиент добавляет
короткую подпись «Фото на документы 3×4, 450 ₽».
