## Обновление и безопасность
- Ветка `main` защищена GitHub ruleset: обязательный Pull Request и проверка `Validate site security`.
- Скрипт проверки: `python scripts/verify_public_site.py`; запрещены неожиданные домены, формы, inline-обработчики, опасные клиентские функции и неподтверждённые назначения.
- CSS/JS локальные и загружаются по HTTPS; политика CSP размещена в HTML meta. Настройки HTTP-заголовков зависят от GitHub Pages.
- Все изменения проверять на узких телефонах и с клавиатуры, а также тестировать переходы к трём ботам. Реальную отправку файла и получение заказа проверять отдельно на тестовых учётных записях, не затрагивая клиентов.

## Фото на документы за 450 ₽ — простой путь отправки

Для формата 3×4 см (6 шт. на листе 10×15 см) клиент открывает #order450, нажимает крупную кнопку «Отправить фото в Telegram, MAX или ВКонтакте». В личном чате FotoMag нужно нажать скрепку или +, выбрать снимок из галереи, написать короткую фразу «Фото на документы 3×4, 450 ₽» и отправить. Большая инструкция по прикреплению фото находится прямо под кнопками. Подробный текст и копирование намеренно спрятаны под необязательным раскрывающимся пунктом. При прокрутке этой секции нижняя плавающая навигация скрывается, чтобы не перекрывать элементы. Отдельно есть кнопка электронной почты с подготовленным письмом, куда снимок нужно прикрепить вручную.

**Сайт не загружает файлы самостоятельно, не подтверждает заказ и не хранит фотографии**; клиентская фотография пересылается в конкретном мессенджере/почте, где сотрудник проверяет снимок, стоимость и готовность. Для других форматов цену нужно отдельно согласовать. Веб-проверка не заменяет реального контрольного заказа через авторизованный мессенджер.
