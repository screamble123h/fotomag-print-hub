# FotoMag — решение по запуску на собственном компьютере (21.11.2026)

**Режим: SELF-HOSTED Windows. Публичный приём клиентских файлов НЕ включён.**

## Что подтверждено

- Тестовый телефонный заказ реально поступил на D:/2026/11/21/Напрямую; пробная Cloudflare Quick Tunnel после проверки была остановлена.
- DESKTOP-P6L7HTI доступен; на компьютере есть архив D:/2026 и подготовленные Python/FastAPI компоненты.
- Windows Security Center показывает Windows Defender в отключённом состоянии: AntivirusEnabled=False, RealTimeProtectionEnabled=False, WinDefend=Stopped. Также зарегистрирован 360 Total Security. Его наличие в Security Center **не подтверждает** пригодность для антивирусной проверки документов в нашем серверном API.
- У текущего пользователя Windows не обнаружено готовой папки ~/.cloudflared с сертификатом/конфигурацией именованного туннеля. Стабильного настроенного HTTPS-домена в ходе проверки не установлено.
- Все три канала VK/MAX/Telegram продолжают работать отдельно. Клиентский сайт в main остаётся без активного приёма «Напрямую».

## Почему нельзя объявить сайт готовым для паспортов и документов

1. Cloudflare Quick Tunnel — временная тестовая ссылка, меняет hostname и не гарантирует доступность. Для named tunnel на постоянном домене нужны Cloudflare account и зона/домен, подключённые владельцем (Cloudflare Docs).
2. Без проверяемой автоматической проверки вредоносных вложений нельзя публично принимать произвольные PDF/DOCX/изображения напрямую на рабочий компьютер FotoMag. 360 Total Security установлен, но **его серверный API и результат сканирования не настроены**. Нужны ClamAV с валидным scanning protocol и обновлением сигнатур или другой интегрированный антивирус.
3. Данные клиентов и документы требуют оформленной политики обработки, реальных реквизитов оператора, срока хранения и оценки допустимости международной обработки/транзита через внешнего посредника (152-ФЗ). GitHub Pages остаётся только интерфейсом и не содержит клиентских файлов.
4. Постоянная служба и GitHub публичная кнопка не должны включаться до успешной проверки всех требований, иначе будет ложная «доставка завершена» или серьёзный риск утечки.

## Условия перехода к рабочему режиму, без VPS

1. Владелец выбирает постоянный домен и подключает его к контролируемому Cloudflare аккаунту или другому HTTPS-провайдеру. При необходимости потребуется пройти вход/создание DNS-записи своими действиями.
2. Настроить named tunnel: только исходящее соединение с компьютера, без открытия портов роутера/Windows.
3. Установить и проверить антивирусный шлюз с проверкой ДО помещения файлов в рабочий архив, независимый карантин, ограничения, мониторинг и резервные копии. Не удалять старые данные FotoMag.
4. Утвердить политику, согласие и реквизиты оператора, проверить условия передачи персональных данных.
5. Пробный заказ с реального мобильного интернета, подтверждение checksum и наличия в D:/2026/MM/DD/Напрямую/клиент/заказ.
6. Включить автозапуск только проверенной службы, затем добавить HTTPS origin в CSP GitHub Pages. При выключенном ПК сайт по /api/health оставляет «Напрямую» недоступным; три мессенджера остаются резервными.
