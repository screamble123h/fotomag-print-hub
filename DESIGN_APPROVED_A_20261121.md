# FotoMag — утверждённый дизайн А «Быстрая отправка»

**Решение владельца:** 21 ноября 2026 года утверждён вариант А из сравнения «FotoMag — прямая отправка фотографий и документов». Вариант Б не используется для запуска канала «Напрямую».

## Что зафиксировано

- Сохраняем прежний QR-код, портал FotoMag и официальный логотип assets/fotomag_logo_official.svg без изменения его геометрии.
- Фирменные цвета: чёрный, белый, жёлтый (в логотипе #FED33C).
- На первом экране портала заметная кнопка «Отправить файл напрямую».
- Внутри — один мобильный экран, без пошагового мастера: «Отправить файлы на печать».
- Три компактных переключателя: «Фото», «Документы», «На документы». Выбранный вариант — жёлтый.
- Главный элемент — крупная зона «↑ Выбрать файлы». Из галереи или памяти телефона.
- Показываются названия/размеры файлов, выводятся безопасным текстом.
- Имя и комментарий необязательные; номер телефона в раскрываемом пункте, также необязательный.
- Обязательное согласие на обработку. Перед публичным запуском нужен действительный текст и ссылка на политику с реквизитами оператора.
- Крупная чёрная кнопка с жёлтым текстом «Отправить в FotoMag →».
- После отправки показывается номер заявки, прогресс и два честных статуса: принят сервером, затем получен компьютером после подтверждения приёмщика.
- На ПК папка заказа: D:/2026/месяц/день/Напрямую/клиент/заказ.
- VK, MAX, Telegram остаются внизу как резерв. Старые ссылки не менять.
- Не добавлять сторонние тяжёлые скрипты, картинки и шрифты, не ухудшать скорость открытия с мобильного интернета.

## Важно

Согласование дизайна НЕ означает включение приёма реальных документов. Действующий main не изменяется до HTTPS-приёмника с российским хранением, защиты от вредоносных файлов, утверждённой политики данных и сквозной проверки передачи на диск D:.

На данном этапе дизайн реализован в черновой ветке feature/direct-upload-20261121 и PR № 11; реальный адрес API ещё не настроен, клиентская отправка заблокирована.

## Приёмочные проверки

1. Узкие экраны телефонов без горизонтальной прокрутки.
2. Три услуги меняют выбор и aria-pressed.
3. Названия выбранных файлов отображаются безопасно, не как HTML.
4. При отсутствии активного API отправка недоступна.
5. VK, MAX, Telegram продолжают работать.
6. Переход к пошаговому варианту Б без нового решения владельца не допускается.
