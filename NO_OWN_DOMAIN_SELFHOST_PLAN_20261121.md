## Без покупки домена

Tailscale Funnel — предоставляет HTTPS-хост вида device.tailnet.ts.net и исходящее соединение с ПК, без доступа к портам роутера. Нужен аккаунт Tailscale, работающий Windows-клиент, включённые MagicDNS/HTTPS и разрешение Funnel. По официальным условиям Personal $0 только для некоммерческого использования; для FotoMag нужен коммерческий тариф, на текущей странице Standard $8/пользователь/месяц. Funnel находится в beta и имеет ограничения пропускной способности, которые нужно проверить на типичных фотографиях. Источники: https://tailscale.com/docs/features/tailscale-funnel и https://tailscale.com/pricing

ngrok Free — закреплённый за аккаунтом домен *.ngrok-free.dev без необходимости собственного домена; ограничение 1 ГБ/месяц и 20 000 запросов, а также экран браузерного предупреждения. Не годится для полноценного объёма фотоцентра без изменения тарифа. Источники: https://ngrok.com/docs/gateway/domains и https://ngrok.com/docs/pricing-limits

## Перед живым приёмом

1. Однократно войти/зарегистрироваться в выбранном сервисе; подключение или оплата провайдера требует участия владельца. Секреты не публиковать в чате и GitHub.
2. Проверить условия российского законодательства 152-ФЗ: юридическая политика, оператор, срок хранения, допустимость транзита через иностранную инфраструктуру и возможной трансграничной передачи. Проверка законности необходима независимо от расположения конечного диска D:.
3. Подключить ClamAV либо другой проверяемый через программный интерфейс антивирус. 360 Total Security зарегистрирован на ПК, но автоматическая проверка через API не подтверждена.
4. Подключить Funnel к отдельному локальному loopback-сервису, а НЕ открывать весь компьютер и НЕ включать staging с отключённой антивирусной проверкой.
5. Настроить автозапуск и мониторинг; при выключенном ПК форма GitHub должна оставаться недоступной, а старые боты работать.
6. Проверить работу на синтетических файлах через мобильный интернет, цифровые отпечатки и отказы. Только после этого активировать реальный API URL в GitHub Pages.
