## Предусмотренная обработка

Цель: приём фотографий, документов и пожеланий клиента для согласования и выполнения услуг FotoMag; обратная связь, если клиент сам оставил телефон. Передаваемые файлы могут содержать изображения людей и сведения из документов; не использовать их для иных целей, обучения моделей, рекламы или публикаций.

Возможные категории данных: имя (добровольно), телефон (добровольно), исходные файлы, комментарий, дата и номер заявки. Для антизлоупотребления сервер временно учитывает необратимый HMAC адреса подключения, не записывая его в файл клиента.

Маршрут: браузер клиента → HTTPS-приёмник, размещённый в РФ → внутреннее антивирусное сканирование → исходящее HTTPS-получение на компьютер FotoMag → локальный архив D:/2026/месяц/день/Напрямую/клиент/заказ. Публичных ссылок на документы нет. Telegram, MAX и VK независимы и регулируются своими условиями.

Доступ: только уполномоченные сотрудники; секрет получения не хранится в исходном коде GitHub/браузере. Автоматической публикации, распознавания лица, автопечати и онлайн-оплаты нет.

Сроки хранения: [СОГЛАСОВАТЬ С ВЛАДЕЛЬЦЕМ] для временной очереди сервера, локального архива и резервных копий. Утверждение должно учитывать обязательные документы учёта и запросы об удалении. **Автоматическое удаление текущим кодом не выполняется**.

Безопасность: HTTPS, лимиты размера и частоты запросов, антивирус ClamAV в закрытой сети, подтверждение доставки по SHA-256, ограничения доступа, резервное копирование и план реагирования на инциденты. Технические меры дополняются необходимыми организационными и правовыми действиями оператора.

## Технический release gate

Пока эта политика не заполнена и не утверждена, не добавлять production URL API в index.html. Текст в согласии на сайте «До запуска публикуются...» — временный; перед выпуском заменить его корректным согласием с активной ссылкой на реально опубликованную privacy.html. GitHub CI должен отклонять релиз с заглушкой.

Источники для правовой проверки:

Не направлять персональные документы в зарубежное облачное хранилище или временный тоннель для демонстрации.
