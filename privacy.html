Данные при прямой отправке файлов

Проект от 22 ноября 2026 года. FotoMag готовит прямой приём заказов. До публикации утверждённых документов отправка клиентских файлов через эту форму закрыта.

Политика обработки персональных данных

Для чего нужны данные

Фотоцентр принимает материалы, чтобы подготовить и выполнить выбранную вами услугу. Имя, телефон для обратной связи и комментарий можно оставить по желанию. Для заказа нужны сами файлы и вид услуги. Отправляйте только сведения, необходимые для выполнения заказа.

Как проходят файлы

По предусмотренной схеме браузер отправляет материалы по защищённому соединению на компьютер FotoMag в России. Там файл проходит антивирусную проверку. Приёмщик сохраняет его в папку заказа и сверяет контрольную сумму. После записи появляется подтверждение доставки.

Для учёта используются номер и время заказа, имена и размеры файлов, статус доставки и контрольные суммы. Для защиты от массовых загрузок приёмник вычисляет из сетевого адреса код с секретным ключом. При открытии страницы на GitHub Pages сам GitHub регистрирует сетевой адрес посетителя. В прямой схеме файлы заказа передаются от браузера сразу в фотоцентр. Сведения GitHub о регистрации адресов

Доступ и использование

Материалы заказа предназначены для уполномоченных сотрудников. Проект предусматривает проверку файлов, ограничение доступа и ручную подготовку к печати. Публикация фотографий, установление личности по изображению и рекламная рассылка выходят за пределы цели заказа.

Обращение по данным

Вы можете запросить сведения об обработке, уточнение, блокирование или уничтожение данных при наличии законных оснований и отозвать согласие. Укажите номер заказа, если он у вас есть. Оператор проверит полномочия заявителя перед предоставлением сведений. Вы также вправе обратиться в Роскомнадзор или в суд.

До открытия формы здесь будут опубликованы полное наименование оператора, адрес для обращений, основания обработки и утверждённые сроки для очереди, архива, журналов и резервных копий. Адрес самого фотоцентра — Ижевск, улица Пушкинская, 173.

Отдельное согласие на обработку данных заказа

Проект текста для согласования. Эту редакцию можно использовать только при проверке формы на искусственных данных.

Я разрешаю оператору фотоцентра обработать переданные мной материалы для приёма и выполнения выбранного заказа. Разрешение касается выбранных файлов и их названий, а также указанных мной имени, телефона и комментария. Разрешённые действия включают получение, запись, проверку, хранение, использование при выполнении заказа, уточнение по моему обращению и уничтожение.

Я могу отозвать согласие через контакт оператора. До открытия формы в этот самостоятельный текст будут внесены полное наименование и адрес оператора, способ отзыва, условия прекращения обработки, срок действия и утверждённая редакция.
