## Шаги после подключения реального VPS

1. Завершить юридические реквизиты и политику (upload_gateway/PRIVACY_POLICY_DRAFT_RU.md); определить сроки хранения. До этого реальных документов не принимать.
2. Создать VPS в РФ и HTTPS-домен, защитить SSH, Docker, серверную сеть, резервирование и мониторинг.
3. На сервере запустить Python bootstrap_server.py --domain действительный-домен --write. Создаёт приватный .env с режимом disabled, не запускает сервисы.
4. Развернуть Docker Compose, проверить ClamAV и сетевые порты. Никогда не публиковать API:8000 и AV:3310.
5. Без передачи секрета через публичный GitHub или чат безопасно перенести агентский токен в локальный agent_config.json и ограничить права NTFS.
6. Сначала запустить агент вручную на Windows через agent_launcher.py. Проверить синтетическую доставку на D:/2026/месяц/день/Напрямую/клиент/заказ; только после проверки включать автозапуск.
7. Испытать смартфон на мобильной сети → HTTPS VPS → ПК → D, сверить checksum, время Ижевска и receipt.
8. Добавить действительный API URL на QR-страницу, включить CSP и ссылку на реальную privacy.html, дождаться CI и только после этого выпускать PR №11 в main.

Запрет: не включать автопечать или автоматическое удаление, не переносить и не менять MAX/Telegram/VK.
