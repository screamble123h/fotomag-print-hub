ОГРАНИЧЕНИЯ:
Страница статическая, не принимает/не хранит фотографии, не создаёт автоматически заказы и не принимает платежи. Клиент прикрепляет фото в личном чате или e-mail и ждёт подтверждения сотрудника. Проверка требований для конкретного документа обязательна.
Авторизация, передача реального фото и поступление заказа через MAX/VK/Telegram в этой локальной серии не тестировались.
