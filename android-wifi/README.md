# FotoMag Wi-Fi: Android 11+

Это небольшое автономное приложение добавляет сеть **AGFA** с заранее заданным паролем **00001111**.

- Работает через официальный `Settings.ACTION_WIFI_ADD_NETWORKS` на Android 11+.
- Телефон сам показывает системное окно подтверждения сохранения AGFA.
- Вводить пароль и искать сеть в списке не нужно.
- Android сам определяет, когда фактически соединяться с AGFA.
- Без доступа к интернету, файлам, контактам, местоположению или сканированию.
- С сайта можно открыть установленное приложение ссылкой `fotomagwifi://connect` или Chrome Intent.
- Приложение не утверждает, что сеть уже подключена, пока Android не подтвердит сохранение.

Сборка (JDK 17, Android SDK 35, Gradle 8.13): `gradle -p android-wifi :app:assembleDebug`.
Отладочная APK требует тестирования на реальном телефоне; для публичного релиза нужна постоянная подпись.
